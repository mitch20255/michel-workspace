🔑 Clé YouTube Data API

Gratuite — 10 000 requêtes/jour. Requise une seule fois.

▸ Comment obtenir une clé gratuite ?
  1. Va sur console.cloud.google.com
  2. Crée un projet (ex: "YouTube NLM")
  3. Menu → APIs & Services → Bibliothèque
  4. Cherche "YouTube Data API v3" → Activer
  5. Menu → Identifiants → Créer des identifiants → Clé API
  6. Copie la clé et colle-la ci-dessus

Comment utiliser

  1. Entre ta clé API une fois (sauvegardée sur ton appareil)
  2. Colle l'URL d'une playlist YouTube
  3. Sélectionne les vidéos à importer
  4. Clique Copier les URLs
  5. Ouvre NotebookLM → ton carnet → + Ajouter une source
  6. Sélectionne URL, colle une URL, répète

💡 Installe cette page sur ton écran d'accueil pour y accéder comme une app. Sur iOS : bouton Partager → "Sur l'écran d'accueil"
